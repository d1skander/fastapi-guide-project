# Проект

## Что за проект?

Данный проект был разработан по заданию преподавателя. Его основная задача — создание интерактивного веб-путеводителя, который помогает людям находить нужные туристические объекты.

Первый рабочий макет приложения был сделан на фреймворке Django. После этого было принято решение перенести проект и переписать его на FastAPI.

## Использованные технологии

- Backend
    - alembic
    - fastapi
    - jinja2
    - sqladmin
    - sqlalchemy
    - uvicorn
    - wtforms

- Frontend
    - html
    - css

- Database
    - sqlite

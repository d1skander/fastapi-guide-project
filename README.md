# Проект

## Что за проект?

Данный проект был разработан по заданию преподавателя. Его основная задача — создание интерактивного веб-путеводителя, который помогает людям находить нужные туристические объекты.

Дали еще 2 недели, и из-за долгого писания кода решил вернуться к Django, ведь нужен уже готовый проект скоро, а Django дает сделать быстро и без вопросов

## Использованные технологии

- Backend
    - Django
    - Pydantic(pydantic-settings)

- Frontend
    - html
    - css
    - javascript

- Database
    - sqlite

## Готовые команды
- uv run main/manage.py runserver
- uv run main/manage.py migrate
- uv run main/manage.py makemigrations
